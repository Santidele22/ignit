# Biblioteca — Sala de lectura

Feature: Implement the authenticated `/biblioteca` view based on `design/ignit-biblioteca/01-sala-escritorio.html` ("Sala de lectura (/biblioteca)") using Astro + SolidJS + real IndexedDB offline storage, current backend APIs (no DB schema migration), own-book edit/delete controls, and dual palette support (`noche-azul` + `original`).
Branch: `feat/biblioteca-sala-lectura`

## Specs

- **S1**: Route `/biblioteca` (`web/src/pages/biblioteca.astro`) replaces the legacy CRUD list with the Sala de lectura layout (`design/ignit-biblioteca/01-sala-escritorio.html`), styled via scoped dual-palette tokens (`web/src/features/library/styles/biblioteca.css` + `web/src/app/layouts/BibliotecaLayout.astro`) that match the artboard verbatim under `noche-azul` (`#04050a`, `#060810`, `#080c17`, `#e6edf7`, `#b9c6dd`, `#8fa4c8`, `#7e91b8`, `#232941`, `#344064`, `#5f86c9`, `#9fc0ee`, zero radius, hairline borders, corner marks on `.resume-card` and `.modal-box`) and adapt semantically under `original` (light and dark), respecting `prefers-reduced-motion: reduce`.
- **S2**: Sticky app topbar (`header.app-top`) renders the `熒 Ignit` brand link, the 4 accessible tabs (`role="tablist"` with `ArrowLeft`/`ArrowRight` navigation and live `.tab-count` badges: `En este dispositivo`, `Mi biblioteca`, `Catálogo`, `Mis aportes`), the online/offline indicator + test toggle (initialized from `navigator.onLine` and syncing `online`/`offline` events, setting `data-offline="true"` on the root container), `+ Subir libro` primary button, a discrete `PaletteToggle` control, and the authenticated `.user-pill` (avatar initial, email, `Salir` button calling `signOut()`).
- **S3**: Top dashboard (`section.hero-dash`) shows the Continuity card (`.resume-card` with bespoke 4/5 SVG cover, kicker, serif title, author + category, excerpt/description quote, progress bar with page & `%`, and `Seguir en Vigilia →` link to `/lecturas/:id`, derived from real reading progress/state with a clean fallback when no books exist) alongside the local storage card (`aside.storage-card` showing real IndexedDB KB/MB used, offline book count, progress bar, `Liberar caché local` button, and `INDEXEDDB · ACTIVO` status).
- **S4**: Real IndexedDB offline storage (`web/src/features/library/lib/offlineStore.ts`) downloads and caches the real `/api/books/:id/reading` JSON + book metadata when clicking `↓ Descargar` (and removes it on `Quitar` or `Liberar caché local`), updates the real KB meter and `En este dispositivo` tab count, disables downloads of uncached books while offline (with grayscale art + `requiere red` badge), announces state changes via `aria-live="polite"`, and wires a safe fallback in `web/src/widgets/reading/loadReading.ts` so `/lecturas/:id` reads cached books from IndexedDB when offline or when network loading fails.
- **S5**: Tabs `En este dispositivo`, `Mi biblioteca`, and `Catálogo` render the 4-column responsive `.rejilla` of `.tomo` cards with bespoke 4/5 SVG covers, spine wire, offline/cloud/network badge, category + progress + pages/size metadata, link to `/lecturas/:id`, and `↓ Descargar`/`Quitar` action. `Catálogo` uses current API categories (`Todos`, `Técnico`, `No técnico`) plus instant normalized title/author/description search (`Buscar título o autor…`).
- **S6**: Tab `Mis aportes` renders the user's owned books in `.aportes-list` with the 4-step pipeline pills (`1 · Standby`, `2 · En curso`, `3 · Tested`, `4 · Catálogo`) derived from existing API fields (`published`, `hasFile`, `kind`, `fileSizeBytes`) without migrating the database schema, including `Ver preview` (`/lecturas/:id`) and `+ Nuevo aporte`.
- **S7**: Modal `+ Subir libro` (focus trap, `Escape` to close, focus restoration) lets the user pick a real PDF file (up to 50 MB, client validation) plus `Título`, `Autor`, `Categoría` (`Técnico` / `No técnico`), and `Descripción breve`, creating the book via `POST /books` and uploading the PDF via `POST /books/:id/file` in one flow before refreshing state and switching to `Mis aportes`. Owned books also expose a discrete `Editar` action opening an accessible modal to edit metadata (`title`, `author`, `description`, `status`, `kind`, `review`, `published`), attach/replace PDF, or delete the book (`PATCH /books/:id`, `POST /books/:id/file`, `DELETE /books/:id`) with confirmation.
- **S8**: All client interactivity uses SolidJS / bundled ES modules (zero new inline script CSP hashes), pure domain/IndexedDB/fallback logic is covered by deterministic Vitest tests, and `pnpm test`, `pnpm astro check`, and `pnpm astro build` pass cleanly.
